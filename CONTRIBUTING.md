# Contributing to OpenPaw

Thank you for helping improve OpenPaw.

## Before you start

1. Search existing issues and pull requests for related work.
2. Open an issue before making a large hardware, protocol, or architecture
   change.
3. Keep safety, accessibility, repairability, and backwards compatibility in
   mind.

## Making a contribution

1. Create a branch from `main`.
2. Keep changes focused and update related documentation.
3. Add or update tests when behavior changes.
4. Use clear commit messages.
5. Open a pull request describing the motivation, implementation, and testing.

Changes to `main` must go through a pull request and satisfy the repository's
required checks and review rules.

## Hardware contributions

Include editable source files, export formats where useful, manufacturing
notes, and bill-of-material changes. Document tool names and versions so other
contributors can reproduce the design.

## Licensing contributions

By contributing, you agree that your work may be distributed under the license
applicable to its repository location as described in [LICENSE](LICENSE).
