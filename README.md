# OpenPaw

OpenPaw is a modular, open hardware platform for pet communication. It combines
interchangeable physical tiles, embedded firmware, a local hub, and a dashboard
for building and studying accessible animal-computer interaction systems.

## Repository layout

- `hardware/` contains CAD, PCB, printable, and bill-of-materials sources.
- `firmware/` contains embedded software for communication tiles.
- `hub/` contains APIs, audio processing, and supporting services.
- `dashboard/` contains the management and visualization interface.
- `labels/` contains label artwork and source assets.
- `examples/` contains reference configurations and integrations.
- `docs/` contains architecture, standards, protocols, and project guidance.
- `tests/` contains cross-component and system-level tests.

Start with [the getting-started guide](docs/getting-started.md), then review the
[architecture](docs/architecture.md) and [roadmap](docs/roadmap.md).
