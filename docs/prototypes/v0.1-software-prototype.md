# v0.1 experimental software prototype

This branch stages a testable one-tile development path without selecting final
production interfaces.

## Hub

The Python package under `hub/` separates validated configuration, protocol
decoding, event routing, and audio. Configuration is explicit JSON and contains
user-facing tile assignments rather than production paths or physical roles in
code. The event queue is bounded. Shutdown cancels and joins tasks within a
configured timeout.

Assigned audio defaults to required: unavailable output, missing or undecodable
files, and failure to obtain a mixer channel raise errors instead of producing a
success-shaped result. A deployment can explicitly mark prototype audio output
or a tile assignment optional.

Install and run the mock event path:

```shell
python3 -m venv .venv
. .venv/bin/activate
python -m pip install -e './hub[audio]'
openpaw-hub --config examples/hub-config.json
```

The example deliberately uses a placeholder discovered identity and relative
paths. Replace it locally; do not commit deployment configuration.

## Firmware

`firmware/tile/` proposes PlatformIO with Arduino for rapid RP2040 prototyping.
The input implementation samples a Velostat/copper-tape pressure divider with
separate press and release thresholds. RGB feedback drives a WS2812B ring using
its addressable one-wire interface.

Arduino/PlatformIO is not the final toolchain. Pin assignments, ADC thresholds,
LED count, brightness, voltage translation, power distribution, and tile
identity remain prototype parameters requiring measured validation.
