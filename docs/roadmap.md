# Roadmap

The roadmap is directional and will evolve as prototypes are tested. A
milestone is complete only when its applicable
[product acceptance criteria](product-requirements.md#acceptance-criteria) are
met.

## v0.1: One tile

- Finalize system architecture and safety requirements.
- Select a prototype tile connector and communication transport.
- Build one RP2040 pressure tile with RGB feedback.
- Discover the tile from a Raspberry Pi 5 hub and play assigned audio.
- Establish reproducible hardware and software development workflows.

## v0.2: Six tiles

- Connect, discover, and operate six hot-pluggable tiles.
- Produce reference CAD, PCB, printable parts, and bill of materials.
- Validate reliability, cleanability, and animal-safe interaction.

## v0.3: Dashboard

- Discover and rename tiles.
- Upload and assign audio.
- Assign tile LED colors.
- Display usage history.

## v0.5: Analytics and integrations

- Add usage analytics beyond basic history.
- Add a Home Assistant integration.
- Add firmware update and diagnostic workflows.

## v1.0: 24-tile system

- Operate a complete 24-tile system.
- Stabilize connector and protocol specifications.
- Publish reference APIs, examples, and conformance tests.
- Document third-party tile development.
- Conduct consent-based pilot studies.
- Improve accessibility, privacy controls, and durability.
- Publish findings and iterate on standards based on evidence.
