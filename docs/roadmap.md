# Roadmap

The roadmap is directional and will evolve as prototypes are tested.

## Phase 1: Foundations

- Finalize system architecture and safety requirements.
- Select a prototype tile connector and communication transport.
- Build a single-tile firmware and hub proof of concept.
- Establish reproducible hardware and software development workflows.

## Phase 2: Modular prototype

- Support discovery and multiple tile capabilities.
- Produce reference CAD, PCB, printable parts, and bill of materials.
- Add local configuration and event visualization.
- Validate reliability, cleanability, and animal-safe interaction.

## Phase 3: Developer platform

- Stabilize connector and protocol specifications.
- Publish reference APIs, examples, and conformance tests.
- Add firmware update and diagnostic workflows.
- Document third-party tile development.

## Phase 4: Field learning

- Conduct consent-based pilot studies.
- Improve accessibility, privacy controls, and durability.
- Publish findings and iterate on standards based on evidence.
