# Security Policy

## Supported versions

OpenPaw is pre-release software. Security fixes are applied to the latest
revision of `main`; no released versions are currently supported.

## Reporting a vulnerability

Do not disclose suspected vulnerabilities in a public issue. Use GitHub's
private vulnerability reporting feature from the repository's **Security**
tab. If that feature is unavailable, contact the repository owner privately
through their GitHub profile.

Include affected components, reproduction steps, impact, and any suggested
mitigation. Avoid accessing data or devices that you do not own or have
permission to test.

The maintainers will acknowledge reports as soon as practical and coordinate
disclosure after a fix is available.
